There is a new chromosome-level, haplotype-resolved genome of A. muscaria on NCBI. This might be really useful for resolving the mating type alleles in my dataset. So I start by mapping the reads to this new genome.


## Read mapping

I have a script which goes through each sample within a site and maps the reads to the reference genome.
```
#!/bin/bash -e
#SBATCH --time=13:00:00         # maximum run time hh:mm:ss
#SBATCH --mem=16G              # maximum memory available to GATK
#SBATCH --cpus-per-task=4

module load BWA
module load SAMtools

setname=$1
echo "${setname}"

for filename in trimmed_shortread_files/trimmed_${setname}*_1.fastq.gz
do
        base=$(basename ${filename} _1.fastq.gz)
        echo "mapping $base"

        bwa mem -M -t ${SLURM_CPUS_PER_TASK} ../ncbi_dataset/data/GCA_988426935.1/GCA_988426935.1_gfAmaMusc1.hap1.1_genomic.fna trimmed_shortread_files/${base}_1.fastq.gz trimmed_shortread_files/${base}_2.fastq.gz > mapped_reads/${base}.sam
        samtools view -S -b mapped_reads/${base}.sam > mapped_reads/${base}.bam
done
```

I can submit this as four jobs at once with the following script. 

```
for setname in T S F H W; do sbatch run_mapping.sl ${setname}; done
```
